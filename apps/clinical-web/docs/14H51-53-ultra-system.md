# neumuuacFQ — Ultra-system visual signature

## Principles

Scientific operating environment: institutional, precise, readable, continuous. The visual system uses restrained dark forest navigation, warm neutral scientific surfaces, a single green interaction accent, strong typography and thin structural boundaries. Avoid neon gradients, competing card colors, oversized marketing panels and unnecessary explanatory paragraphs.

## 14H51: system-wide foundations
The additive `ultra-system.css` layer is imported after existing styles to consolidate visual tokens, shell spacing, navigation selection, type hierarchy, form controls and surfaces. CSS-only; underlying variant data, permissions, search ranking and therapy calculations remain unchanged.

## 14H52: primary research experience
Search results should lead with the variant identifier and selected state, followed by secondary classification and provenance. Therapy comparison emphasizes the recorded result and independently labels recorded variant-response fields versus genotype-rule-only rows. Responsive mobile presentation uses a controlled two-column regimen row that exposes details without cramped typography.

## 14H53: connected workspaces
Evidence, genotype, variant dossiers and the shared header inherit a consistent visual grammar. The navigation uses clearer active states, predictable touch targets and mobile-first layout. Research administration and Helios still require dedicated component-by-component design and interaction audits; do not claim that the entire platform is redesigned.

## Acceptance criteria
- Test at viewport widths 320, 375, 390, 768, 1024 and 1440 px.
- Ensure no horizontal overflow, covered headers, hidden menu controls or clipped research findings.
- Verify keyboard focus order and reduced-motion behavior.
- Compare variant, genotype, evidence, Helios and admin routes on mobile and desktop.
- Confirm that ETI/Alyftrek recorded results, Class I exception handling, scientific source evidence and geographic event gates are unmodified.
- Complete Playwright browser and TypeScript checks in GitHub Actions, then inspect the actual deployed site.

Status: first CSS foundation committed. Live visual acceptance and subsequent micro-interaction refinements remain pending.
