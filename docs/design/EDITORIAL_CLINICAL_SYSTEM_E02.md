# neumuacFQ · Editorial E02 — Clinical control precision

## What E01 taught us

The new E01 typography and palette passed TypeScript checks, but browser regressions detected direct conflict with proven original-shell colors and exact compact filter geometry. These were corrected rather than rewriting existing acceptance tests.

- Institutional sidebar restored to original navy `#0C1422`.
- Main canvas restored to original neutral `#F4F5F7` across daylight/midnight transitions.
- Variant filter and saved-review utility controls explicitly retain transparent idle backgrounds.
- Existing scientific interpretation markers are neither recolored nor regenerated.

## E02 implementation

A narrow, final-loaded CSS layer refines **existing real controls**, not generic imagined component types:

- Variant discovery: search input, active focus, filter trigger, saved/session/batch utilities, and popup filter.
- Workspace launcher: searchable options and precision focus indicators.
- Workspace home: search form control anatomy and primary action optical consistency.
- Genotype comparison, evidence coverage and audit: search field fit and button hierarchy.
- Governance and geographic selection: bounded typographic/radius consistency, without remapping scientific states.
- Keyboard-accessible focus, minimum functional hit-targets, and reduced-motion support.

No authentication, medical rules, data, navigation behavior, local-storage semantics, or the original HTML were changed.
