# Phase 14H13 — Unified five-therapy variant workspace

**NFQ-014, NFQ-015, NFQ-026 and NFQ-038.** The original five-modulator structure is now the visual basis of the variant dossier, replacing an ETI-only module.

- A compact five-row therapy list shows ETI and Alyftrek **recorded variant-response values** and Kalydeco, Symkevi/Symdeko, and Orkambi as **genotype-rule coverage** with no invented variant-response states.
- Initial ETI details remain discoverable. Selecting a therapy expands just its source metadata, with source-linked records and original technical values available under ETI.
- Reads remain exact-ID, GET-only and abortable, with visible errors and retry. The scientific class and subtype appear as separate identifiers and never overwrite response data.
- Evidence navigation returns to the existing variant-scoped workspace. The parent controls the real Sources & Validation disclosure, avoiding invisible content expansion.
- Presentation uses one row-oriented panel, restrained typography, accessible details buttons, and mobile reflow; no duplicated five-color card grid.
- No genotype eligibility inference, patient response calculation, regulator update, review decision, clinical write, RLS modification or geographic recording.

Phase 14H14 connects this workflow to actual review evidence, context-rich scientific triage, and a review packet action; Helios approvals remain unavailable unless a verified server-side review endpoint is available.
